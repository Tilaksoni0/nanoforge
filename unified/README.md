# Unified version

This directory is intentionally kept alongside the modular code.

The purpose is educational:

    unified/
        one-file version of the current system

    src/
        the same conceptual system split into modules

Use `unified/` to trace the complete execution path quickly.
Use `src/` to learn how a real repository separates responsibilities.

As the project grows, the unified version can become a compact
reference implementation rather than a second production codebase.
